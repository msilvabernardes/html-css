TAG's HTML (As que consegui lembrar de cabeça haha!)

Em HTML usamos diversas TAG's que correspondem a "comandos" para inserir determinados elementos no seu site. Veja abaixo alguns desses elementos e passe o mouse por cima de cada um para ver a TAG correspondente

  1. Parágrafo
  2. Título (OBS: níveis de 1 a 6)
  3. Linha demarcadora entre o título e corpo do site
  4. Lista não ordenada
  5. Lista ordenada
  6. Adicionar imagens
  7. Adicionar links
  8. Quebrar parágrafos
  9. Fazer comentário (Apenas para controle do seu prompt)
  10. Inserir emoji (clique aqui para acessar a lista de códigos de emojis)
