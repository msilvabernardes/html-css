Este exercício nada mais é do que um arquivo para eu ficar brincando com as funções de declarar emoji neste site


Para declarar um emoji, use o site do link abaixo para pesquisar um emoji


https://emojipedia.org


Ao acessar o site, clique em "Smileys"


Escolha o emoji a ser utilizando no seu código


Nesta janela, acesse "technical information"


Guarde o codepoint do seu emoji


Agora, basta inserir o seu emoji no seu prompt utilizando a seguinte sintaxe: "&#x(número codepoint do seu emoji)"


Por exemplo: "🖖"
