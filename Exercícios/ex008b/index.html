Outras formatações

Código-fonte / Pré-formatação

A tag <code> serve para formatar os caracteres de uma forma mais legível quando você quiser apresentar um código no seu texto.

Exemplo: O código a seguir "document.getElementaryById('teste')" foi escrito sem usar a tag <code>

Exemplo: O código a seguir "document.getElementaryById('teste')" foi escrito usando a tag <code>


Também é possível escrever códigos no seu texto no mesmo padrão de formatação que é observado nas linhas de código usando a tag O código a seguir "document.getElementaryById('teste')" foi escrito sem usar a tag <pre> Exemplo:

        
num=int(input('Digite um numero'))
if num%2==0:
    print(f'O numero {num} é PAR')
else:
    print(f'O numero {num} é IMPAR')
print(f'fim fo programa')

Citações Simples

A tag <q> pode ser usada para fazer uma citação em um texto. Ex: Como diria um pai de um amigo, O computador é um burro muito rápido

Citações completas

É possível fazer uma citação mais elaborada usando a tag <blockote>

Segundo Rob Nelson, chefe de desenvolvimento do GTA 6 e co-diretor da Rockstar North:

A intenção é criar um universo em que as ações de Jason e Lucia tenham consequências mais perceptíveis, incluindo reações de NPCs a situações que antes poderiam passar despercebidas.

Abreviações

A tag <abbr> é utilizada para explicar abreviações. Ex: Estou estudando HTML e CSS. Estou curtindo pakas
