SEMÂNTICA

A semântica no HTML é o uso de tags que dão significado real ao conteúdo de uma página, em vez de definir apenas a sua aparência


Escrever HTML semântico significa escolher o elemento correto para cada tipo de informação. As TAG's semânticas Indicam claramente qual é a função do conteúdo que está dentro delas (como <header> para cabeçalhos ou <article> para artigos).


As TAG's não semânticas Como <div> e <span>, são genéricas e não explicam o que o texto ou dado representa.
