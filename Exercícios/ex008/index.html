Principais formatações

Negrito

Nesta frase temos um termo em negrito usando a tag <b> (não semântico)

Nesta frase temos um termo em negrito usando a tag <strong> (semântico)


Itálico / Ênfase

Nesta frase temos um termo em itálico usando a tag <i> (não semântico)

Nesta frase temos um termo em ênfase usando a tag <em> (semântico)

Texto marcado

Podemos criar, também, um texto texto marcado usando a tag <mark>

É possível mudar a cor da marcação introduzindo o comando "style" (não é tag) dentro da tag <mark>. Mas isso é estilo e deverá ser aprendido de formas mais apropriadas utilizando o CSS

Texto grande e pequeno

Estamos criando um texto grande utilizando a tag <big> (obsoleto) e um texto pequeno utilizando a tag <small>

Texto deletado

Podemos marcar um texto como excluído utilizando a tag <del> para indicar que ele deve ser lido, mas não considerado

Texto inserido

Podemos marcar um texto inserido utilizando a tag <ins> para dar uma ênfase e indicar que ele foi adicionado depois

Existe também o sublinhado que é feito com a tag <u> (não semântico)

Texto sobrescrito

A tag <sup> é usada para escrever potências em equações (ou simplesmente elevar os caracteres de um texto), como por exemplo: X2+3

Texto subscrito

De forma análoga, a tag <sub> é usada para escrever índices de moléculas químicas como por exemplo: H2O
